# 上下文接入与 MCP 课程示例笔记

这份文件是本实验自带的可修改示例资料，展示本地上下文如何影响 Agent 回答。

## 上下文为何必要
模型的训练知识不知道当前文件中的课程笔记、个人任务截止日期或剩余阅读用时。
通过工具取得当前文件内容，才能使回答随本地环境变化而变化。
更改 CSV 中的预计用时后，排期结果必须随之改变，这可以验证系统确实读取外部上下文。

## 两种标准接入方式
MCP 使用客户端与服务端结构，通过标准协议暴露工具和资源。
标准 LLM Function Calling 使用 JSON Schema 描述函数，并以工具消息返回执行结果。
本实验选择标准 Function Calling，符合任务中 MCP or similar 的要求，不额外运行 MCP 服务。
资料读取和 CSV 分析是两个独立功能技能，资料搜索用于定位应该读取的文件。

## 非可信资料
本地资料也可能包含“忽略系统提示词”等提示注入文本，应作为资料内容处理。
资料工具限制在 data/library 范围内，不能通过相对路径跳转到密钥等其他文件。
PDF 读取需要限制文件大小与页数，并为扫描件提供明确的 OCR 提示。

## 内容驱动的学习计划
CSV 是真实数据资料，工具分析列类型、缺失值、数值统计和类别分布，不要求它包含预制学习任务。
模型阅读原文后按完整知识主题确定学习目标、先修关系、难度和建议用时，页码只用于定位和检查覆盖。
规划工具要求引用实际读取过的内容，先修单元先学，每天不超过预算，也不按剩余分钟任意切断定义、证明或例题。
若完整单元放不进当日预算或全文尚未覆盖，应明确说明缺口；难度与用时是学习建议，不是资料中的客观事实。
